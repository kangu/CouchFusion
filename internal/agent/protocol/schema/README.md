# Codex app-server protocol fixture

This directory contains the experimental JSON Schema bundle generated by the
Codex version recorded in `VERSION`:

```bash
mkdir -p internal/agent/protocol/schema
codex --version > internal/agent/protocol/schema/VERSION
codex app-server generate-json-schema --experimental --out internal/agent/protocol/schema
```

The CouchFusion client intentionally implements only the reviewed protocol
surface it needs:

- `initialize` and `initialized`;
- `account/read`;
- `skills/extraRoots/set` and `skills/list`;
- `thread/start`, `thread/resume`, and `thread/read`;
- `turn/start` and `turn/interrupt`;
- thread, turn, item, message-delta, and `serverRequest/resolved` notifications;
- command, file-change, permission, and user-input server requests.

Before replacing this fixture, regenerate it with the installed Codex binary,
review changes to those methods and their decision enums, update the typed Go
surface and contract tests, and run `go test -race ./internal/agent/protocol`.
Schema changes must not be copied into browser-facing DTOs.
